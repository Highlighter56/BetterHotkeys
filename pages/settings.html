Better Hotkeys

Keyboard shortcuts for common Chrome tab operations. Chrome controls the final shortcut assignment and may reserve some combinations.

To change a shortcut, open Chrome's extension shortcuts. Browser- and operating-system-reserved shortcuts cannot be overridden.

Commands

    Highlighting note

    The previous and next commands activate adjacent tabs without clearing the existing highlighted selection. Alt+Shift+Up toggles the active tab's highlighted state. Chrome limits extensions to four default shortcut assignments; remaining commands can be assigned in Chrome's shortcut page.
